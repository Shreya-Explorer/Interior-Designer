# Interior Designer Website

A simple and elegant **Interior Designer demo website** built using **HTML and CSS**. The project showcases a modern interior design portfolio with responsive layouts, room design sections, image galleries, and a clean user interface suitable for a home decor or interior design business.

## Features

* Responsive homepage layout
* Interior design portfolio sections
* Living room, bedroom, kitchen, and bathroom showcases
* Modern typography and color palette
* Image gallery integration
* Clean and user-friendly design

## Technologies Used

* HTML5
* CSS3
